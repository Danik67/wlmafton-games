WlmAfton Games v0.2 — инструкция
================================

Сайт: index.html
Панель администратора: admin.html
Настройки Supabase: supabase-config.js
SQL для базы данных и хранилища: supabase/schema.sql

НАСТРОЙКА BACKEND
1. Создай проект на https://supabase.com/
2. В Project Settings → API скопируй Project URL и anon/public key.
3. Вставь их в supabase-config.js. Никогда не вставляй service_role key в браузерный код.
4. В Supabase → SQL Editor выполни весь файл supabase/schema.sql.
5. В Authentication → Users создай пользователя с email и сильным паролем.
6. Скопируй UUID пользователя и выполни в SQL Editor:
   insert into public.admins (user_id) values ('ТВОЙ-UUID');
7. После публикации открой https://ТВОЙ-ДОМЕН/admin.html и войди.

ДОБАВЛЕНИЕ ИГР
1. В панели заполни название, жанр, статус, код и описание.
2. Загрузи ZIP/EXE или вставь прямую ссылку на файл.
3. Отметь публикацию и нажми «Сохранить игру».
4. Опубликованные игры появляются на главной странице.
5. Снять галочку публикации — скрыть игру из публичного каталога.

ПУБЛИКАЦИЯ
1. Создай публичный репозиторий на https://github.com/
2. Загрузи в корень репозитория все файлы этой папки.
3. GitHub → Settings → Pages → Deploy from a branch → main → /(root) → Save.
4. Сначала сайт будет доступен по адресу github.io.
5. Для собственного домена купи домен у регистратора и добавь его в GitHub Pages → Custom domain.
6. Настрой DNS по инструкциям GitHub у регистратора. После обновления DNS включи Enforce HTTPS.

БЕЗОПАСНОСТЬ И ОГРАНИЧЕНИЯ
- В клиентском файле разрешён только Supabase anon/public key. Не публикуй service_role key, пароль БД или пароль админа.
- RLS-политики в schema.sql ограничивают управление играми пользователями, UUID которых вручную добавлен в admins.
- Bucket game-files публичный: любой человек со ссылкой сможет скачать опубликованный файл.
- SQL-шаблон задаёт максимальный размер файла 500 MB, но фактические ограничения зависят от тарифа и настроек Supabase.
- Для крупных EXE/ZIP релизов удобнее GitHub Releases или itch.io; в поле загрузки можно указать прямую ссылку.
- Перед публикацией замени контактный email contact@wlmaftongames.com в index.html на свой реальный адрес.
- Панель v0.2 управляет играми. Новости, скриншоты, видео и системные требования добавим позже.
